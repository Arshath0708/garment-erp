# Guru Traders ERP

Guru Traders ERP is an Export Trading Management System built using Laravel 12.

## Tech Stack

- Laravel 12
- PHP 8.3
- MySQL 8
- Blade
- Bootstrap 5
- AdminLTE 4
- Spatie Laravel Permission

## Features

- Dashboard
- Masters
- Inquiry Management
- Quotation Management
- Order Confirmation
- Purchase Order
- Inward Management
- Packing
- Export Documents
- Purchase Bills
- Reports
- User & Role Management
- Settings

## Installation

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
